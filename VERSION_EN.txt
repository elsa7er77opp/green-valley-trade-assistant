WHAT IS NEW IN 1.0.0
--------------------
1. The Settlement field follows the selected side.
   BUY  -> locked to NORMAL (a BUY ticket has no settlement
           field in Aspire at all)
   SELL -> cleared, options become T+0 / T+1 / T+2 only

   The same rule is enforced in the plan model, not only in the
   user interface: a BUY plan carrying T+n and a SELL plan
   carrying NORMAL are both refused before they reach Aspire.

   The tool still never chooses a settlement period for the
   user. That is why switching to SELL empties the field rather
   than filling in a period.

2. Diagnostics are no longer written to Downloads automatically.
   The last 10 captures are always kept inside the extension,
   and one button in the extension popup exports them on demand.
   Automatic writing can be re-enabled from the same popup.

KNOWN LIMITS
------------
- An Edge extension that is not published to the store must be
  loaded manually once via Load unpacked. No installer can do
  this step.
- After installation the extension receives a new ID in Edge, so
  the pairing token must be pasted once more.
- Aspire does not show the settlement period on its confirmation
  screen, so it cannot be verified there. The value seen on the
  ticket is the only reference.
- POSTCHECK_NOT_VERIFIED does not mean the order was not sent.
  Check Aspire yourself before repeating any plan.


NOTICE
------
This program is an execution and assistance tool, not an
investment advisory tool. Every decision to buy, sell, price or
time an order belongs to the user alone, and Sponsor Mode sends
real orders with real money.
